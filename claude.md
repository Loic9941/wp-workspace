# wp-workspace

Repo d'orchestration. Contient deux submodules indépendants :
- [wp-core](https://github.com/Loic9941/wp-core) — plugin WordPress réutilisable
- [wp-starter](https://github.com/Loic9941/wp-starter) — boilerplate site client

## Cloner ce repo

git clone --recurse-submodules https://github.com/Loic9941/wp-workspace.git

## Mettre à jour les submodules

git submodule update --init --recursive
